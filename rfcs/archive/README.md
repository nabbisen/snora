# Archived RFCs

Withdrawn or superseded. An RFC lands here when the question it asks stops
being the right question — not when its answer turns out to be "no".

**An archived RFC is not deleted and not wrong.** It is kept because the
reasoning that made it obsolete is usually worth more than the RFC was, and
because a question that was once worth asking tends to be asked again.

Each file records, at the top, **what superseded it and why**.

## Why this folder was empty until 0.39.2

snora adopted the lifecycle policy's five-folder variant on 2026-08-19 and
created `archive/` on first use, per the policy. RFC-078 is the first entry.
